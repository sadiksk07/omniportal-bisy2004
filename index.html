1. Project Overview, Charter & Scope

Lead: Tanvir Ahmed (238983)

Business Need & Problem: Apex Metropolitan University currently operates four disconnected student-facing portals: a legacy Blackboard LMS, Ellucian Banner SIS for enrolment, TouchNet for fee billing, and Zendesk for student support. Disjointed logins force students across multiple interfaces, generating 4,200 repetitive helpdesk calls per semester, an 18% record desynchronization rate, and $185,000 in annual multi-vendor maintenance contracts.

Project Purpose & Objectives: The purpose of Project OmniPortal is to consolidate all student-facing administrative and academic workflows into a single cloud-native responsive platform. The four core project objectives are: (1) Deliver production cutover within 24 weeks prior to Semester 1 enrolment; (2) Remain within the approved $450,000 budget envelope; (3) Achieve 100% data fidelity migrating 28,000 student academic profiles; and (4) Attain 99.95% system uptime under peak concurrent loads.

Development Lifecycle: A Hybrid Agile-Waterfall methodology is deployed. Predictive Waterfall governance manages charter sign-off, enterprise architecture, security compliance, and final blue-green cutover. Two-week Agile sprints execute iterative UX prototyping, feature coding, and ETL data migration scripts.

In-Scope Deliverables Explicit Project Exclusions
• Centralized Single Sign-On (SSO) with MFA authentication.
• Real-time course cart enrolment, timetable builder, fee processing.
• Automated ETL migration of 28,000 student historical records.
• WCAG 2.1 AA accessible web and responsive mobile client.		 • Migration of legacy HR and payroll enterprise systems.
• Development of native iOS/Android binary app store packages.
• Overhaul of physical student smartcard campus turnstiles.
• Ongoing operational helpdesk staffing beyond hypercare.
